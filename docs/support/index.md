# 支持型号

从 1.2.0 起项目改为统一 APK；当前已接入下列 21 个型号（含 FreeClip 2 典藏版）。FreeBuds Pro 2 从 1.9.3 起提供；FreeBuds 4 兼容适配从 1.9.2 起提供，待本机型实测。

本分支在 1.9.1 协议底座上接入 ColorOS 系统能力；新型号的本轮 ColorOS 表现仍需实机验证。

下表列出已接入的能力；未列出的官方功能不代表已经支持。实际可用项会受到耳机固件、ColorOS 和系统组件版本影响。

## 使用边界

- 系统入口、官方弹窗与流体云会随 ColorOS 固件和宿主组件变化，本轮尚需实机验证。
- 6i／SE 4 ANC 的部分音效、防风噪操作复用蓝牙进程控制通道；手动低时延操作优先于排队中的自动开启。
- 低时延写出成功不等于耳机状态回读，专属型号的回读范围以对应适配记录为准。
- 第一代 FreeClip 不提供传统主动降噪或自定义 EQ；FreeArc 仍不展示未经完整抓包确认的低时延开关。
- 改名仅影响展示，协议路由与配置继续按真实身份和蓝牙地址识别。
- 安装与作用域见[快速开始](../guide/getting-started.md)，来源及实机待测项见[本轮移植记录](../coloros-port-20261020.md)。
- 误选型号后，可在设备列表的机型编辑菜单中“恢复自动识别”，移除映射并保留系统蓝牙配对和连接；操作方法见[快速开始](../guide/getting-started.md#选错机型时恢复自动识别)。
- FreeBuds Pro 2 与 FreeBuds 4 随上游 1.9.3 / 1.9.2 同步接入，协议依据群友抓包与官方配置，尚未在 ColorOS 上实机验证。
