# FreeBuds 4 兼容适配

1.9.2 基于官方客户端和同族协议新增兼容适配，待 FreeBuds 4 实机验证。

## 依据

- 华为智慧音频 2.0.4.370 的 `000129.json` 明确记录 FreeBuds 4 / Hero / ZA09；4E 为 `000135` / HeroE / ZAA4。
- `config_ZA09.json` 与 `config_ZAA4.json` 的 `noiseControl` 完全一致：现代协议、两态降噪、支持档位，不提供智慧动态、深度或人声通透。两者使用同一 NoiseControl、EqAdjust、TouchSetting 与 WearDetection 服务。
- 官方 NoiseControlApi 的现代降噪写入经 `w3.b.K0` 调用 `z3.d.J3`，生成 `2B 04 01 02 mode level`；状态查询为 `2B 2A 01 00`，与现有 4E 协议一致。
- 官方 ZA09 手势引导包含双击、按住切换降噪，以及固定上下滑动调音量。其他动作与音效沿用 4E 共用协议，仍需在 FreeBuds 4 上逐项核对。
- 2026-10-20 查询华为官方 CDN，`000129/000129.json` 返回正确产品信息，白色 `00`、银色 `01`、红色 `02` 资源 ZIP 均返回 HTTP 200。实际图片仍按设备报告或用户选择的配色获取，不用 4E 图片替代。

## 当前兼容范围

独立机型识别、地址绑定、左右耳和盒电量、官方图片、降噪 / 关闭、轻度 / 均衡档位、双击和按住动作、佩戴检测，以及默认 / 低音增强 / 高音增强音效。系统页面使用对应的两态控制，滑动只展示固定音量说明。

此前将 FreeBuds 4 手动绑定为 4E 的用户，安装本次测试包后请改选 FreeBuds 4；模块不会静默覆盖用户已有的机型绑定。

暂不支持通透、三击、自定义滑动、低时延、空间音频、十段 EQ 或双设备管理。听歌识曲等依赖华为手机服务的动作在小米手机上未必生效。

## 验证

回归覆盖独立身份与图片目录、4/4E/4i 名称隔离、两态降噪与非法档位拒绝、共用音效和手势编码。协议测试不等于实机通过：需后续对照耳机实际响应、官方 App 状态、重连电量与图片；异常时再定向补日志或抓包。

2026-10-20 本地测试通过单元测试、Debug / Release lint、Release 构建和正式证书校验。相关改动已纳入 1.9.2，保留 API 102 与热重载配置。
