# HuaweiPods ColorOS 快速开始

本指南适用于 Nshpiter 的 `coloros` 分支。当前为未发布的 1.9.1-coloros.1-rc1 开发候选。

## 环境

Android 15+，目标系统为 ColorOS 16／17；需要支持 LSPosed API 101 或 102 的框架。API 102 提供覆盖安装后的自动热重载。ColorOS 17 的参考适配包含静态核对，不能视为本轮真机验证通过。

## 安装

1. 安装本分支 APK，确认包名为 `moe.chenxy.huaweipods.coloros`。本地 Debug 包仅用于测试，不与正式签名包混用。
2. 在框架中启用模块，勾选 `com.android.bluetooth`。
3. 使用官方连接弹窗时勾选 `com.heytap.accessory`；使用“我的设备”时勾选 `com.heytap.mydevices`。
4. 可选勾选 `com.oplus.wirelesssettings`，用于系统蓝牙详情入口；已安装华为智慧音频时可选 `com.huawei.smartaudio`。
5. 首次打开模块，授予蓝牙和通知权限。在系统中允许自启动及后台活动，并开启实时通知／流体云。
6. 重启所选作用域或手机，随后连接耳机。API 101 框架更新模块后也需要重新加载作用域。

现代型号优先读取真实协议身份与配色；识别失败时可按蓝牙地址手动指定型号。图片下载失败时回退到缓存或内置图。

## 共存与更新

- 本包与主线 HyperOS 版和 Artifical0 版应用 ID 不同，不会覆盖它们或自动迁移应用数据。
- 同一系统作用域只启用当前使用的适配模块，避免多个模块同时接管同一耳机。
- 更新只筛选 Nshpiter/HuaweiPods 仓库的 ColorOS 标签。稳定版忽略 RC／Beta，测试版可检查同渠道候选版本。
- 不会通过仓库通用 Latest 获取 HyperOS 安装包。

## 功能边界

私有宿主签名不匹配时，相应系统入口可能不可用。先确认作用域已加载，再记录手机固件、宿主组件版本、耳机型号及复现步骤。不要公开未经脱敏的蓝牙地址或原始采集日志。

低时延写出确认与耳机状态回读不同；大部分机型只能显示最近成功写入的设置。FreeBuds 6 的回读能力以主线适配记录为准。
