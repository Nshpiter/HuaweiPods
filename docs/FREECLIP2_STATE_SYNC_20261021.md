# FreeClip 2 设置状态同步

本页记录的状态同步、界面和通知改动已纳入 1.9.2。

## 问题与修改

此前佩戴检测、掉落提醒、智感音量自适应、双设备和盒提示音在模块页面使用本地设置记录，低时延使用自动应用期望值。这些值不能代表在智慧音频或其他设备上修改后的实际状态。

现在页面进入或恢复前台时，批量读取上述六项以及头动控制、嘈杂环境大音量；读取过程中禁用操作，缺失的返回值显示“未读取到耳机状态”，不填充为关闭。支持手动刷新。修改后回读确认，通用 ACK 不作为开关值。头动动作保留点头 / 摇头的独立设置。

低时延由蓝牙宿主写入，页面显示耳机回读状态；自动应用设置仅在用户修改成功后保存。

查询在可见页面进入 / 恢复以及手动刷新时触发，没有新增后台周期轮询。过期查询不能覆盖较新的页面状态，暂停或离开页面后不应用旧查询结果。

## 协议证据

来自 2026-07-29 FreeClip 2 智慧音频采集，包含 TX 查询及 RX 返回。普通版与典藏版共用现有 FreeClip 2 路由，典藏版仍需实际验证本次改动。

| 设置 | 查询 / 状态字段 |
| --- | --- |
| 佩戴检测 | `2B11`，TLV `01` |
| 掉落提醒 | `2BB4`，功能 `07`，TLV `02` |
| 智感音量自适应 | `2BB4`，功能 `02`，TLV `02` |
| 低时延 | `2B6C`，TLV `02`；不把 TLV `03` 或 ACK 当开关 |
| 双设备 | `2B2F`，TLV `01`；不新增双设备列表管理 |
| 充电盒提示音 | `2BB1`，TLV `02`；与 TLV `03` 区分 |
| 头动控制 | `2BB4`，功能 `0B`，TLV `02/03/04` |
| 嘈杂环境大音量 | `2B88`，TLV `01`；不使用能力字段 `02` |

编解码复用现有实现，使用采集中的响应验证状态解析。

## 界面

依据 [miuix skill](https://github.com/limczhh/miuix-skill) 的组件选择与分组建议，将 FreeClip 2 开关改为 `SwitchPreference`，选项入口使用 `ArrowPreference`，互斥选项使用 `RadioButtonPreference`。用 `SmallTitle` 和独立 `Card` 区分空间音频、音效、智能功能、声音与连接，沿用已有主题和页面容器。

skill 的文档基于 0.9.4；项目继续使用 0.9.2，实际调用已对照 0.9.2 源码，未升级 UI 核心依赖。调试构建包含不连接耳机、不保存设备设置的预览入口；交付的 Release 测试包不包含该入口或抓包界面。

## 实机核对

本地验证：543 项单元测试全部通过，Debug / Release lint 无错误，两种构建及网站构建通过。Release 测试包通过正式证书、ZIP 对齐和 API 102 热重载元数据校验，不包含调试预览 Activity。

Android 36.1 模拟器检查了深色 / 浅色、未知状态禁用、130% 字号、头动展开及单选弹窗。耳机同步和 HyperOS 集成仍待实机验证。

安装后，在智慧音频修改开关并返回模块核对，再从模块修改并对照智慧音频。低时延另需核对重连后的自动应用。

## 2026-10-22 测试包修订

- 自定义音效入口统一为 miuix 设置行，对齐标题、摘要和右侧箭头。
- FreeBuds 7i 根据用户反馈校正空间音频：`1` 为头部跟踪、`2` 为固定，写入和回读同时调整。
- 通知增加投递确认；未确认时补发一次当前连接设备的电量快照，通知恢复不再连带查询音效、降噪等状态。群友的偶发缺失问题仍待实机验证。
