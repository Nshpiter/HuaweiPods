# FreeBuds Pro 2 适配说明

从 1.9.3 起提供。依据 2026-10-28 的 1,983 条协议事件及官方 ZAA7 配置接入，协议解析和构建已验证，各控制项仍待群友实机复测。设备身份为 `000131/0E`，固件 `4.2.0.258`；抓包中的官方深腈色资源已下载成功，含主图及左右耳图片。

| 功能 | 接入内容 |
| --- | --- |
| 识别与图片 | 独立 Pro 2 路由，官方白 / 深腈 / 蓝紫配色目录；Pro 2+ 不归入该型号 |
| 电量 | 左耳、右耳与充电盒，沿用已核对的 `01/08` 帧 |
| 噪声控制 | 关闭 / 降噪 / 通透与状态回读；智慧动态=3、轻度=1、均衡=0、深度=2；普通通透=2、增强人声=1 |
| 音效 | 默认=5、低音=2、高音=3、清晰人声=9、古典交响=200、Hi-Fi 现场=201，10 段自定义均衡器 |
| 手势 | 左右长按、播放 / 下一曲 / 上一曲捏合开关、滑动音量开关、佩戴检测；听歌识曲依赖手机侧服务 |
| 连接 | 双设备连接开关、高清音质、低时延及重连自动应用 |

空间音频在本次采集标记为跳过，未接入。充电盒提示音无操作数据；语音相关命令尚缺具体功能名称对应；耳塞贴合测试和连接中心的优先设备管理也未开放。

测试时优先对照智慧音频检查四档降噪、普通 / 人声通透、六种音效，再确认捏合、滑动和双设备开关的回读。关闭智慧音频后测试低时延开关与重连自动应用；高清音质的实际编码还取决于手机协商结果。
